# 🩸 Online Blood Donor & Emergency Finder

A web-based Blood Donor Management System built using **Python (Flask)**, **HTML5**, **CSS3**, **JavaScript**, and **MySQL**. This application enables users to register as blood donors, search for donors based on blood group, and request blood during emergency situations.

---

## 📌 Project Overview

The **Online Blood Donor & Emergency Finder** is designed to connect blood donors with people in need. It provides a simple, secure, and user-friendly platform where users can register as blood donors, search for donors based on blood group, and submit emergency blood requests.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/satyamsingh88/online-blood-donors.git
```

### Open the Project Folder

```bash
cd online-blood-donors
```

### Install Required Packages

```bash
pip install flask
pip install mysql-connector-python
```

### Import Database

Import the **database.sql** file into your MySQL Server.

### Run the Project

```bash
python app.py
```

### Open in Browser

```
http://127.0.0.1:5000
```
